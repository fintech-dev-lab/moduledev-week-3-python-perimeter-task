# Действующая редакция требований

Этот репозиторий содержит самостоятельную редакцию контракта `week-3.1`. Для выполнения и проверки недели 3 не нужны файлы из родительского каталога или другая копия комплекта курса.

Источники требований:

1. [Условие задания](../task/assignment.md) задаёт обязательный результат.
2. [Полный контракт недели 3](04-week-3.md) задаёт предметные и архитектурные инварианты.
3. [Внешние HTTP-контракты](external-contracts.md) задают точные запросы, ответы и повторы.
4. [Конфигурация и запуск](configuration.md) задаёт Compose seam, переменные и начальную настройку.
5. [Контур автопроверки](07-autocheck-outline.md) задаёт проверяемые seams и сценарии.
6. [Machine-readable contracts](../contracts/course-1) являются нормативными для формы опубликованных JSON payload/result.

При расхождении prose с JSON Schema для формы JSON действует schema. При расхождении этого репозитория с прежним черновиком Week 3 действует этот репозиторий.

## Отзыв прежней спецификации receipt v1

До начала выполнения задания отозван черновик, в котором provider сам формировал HMAC по строке полей с LF, а `providerPaymentId` мог быть `null`.

В действующей редакции:

- provider v0.2.0 отправляет legacy callback без HMAC;
- Python adapter формирует и подписывает compact sorted JSON;
- HMAC считается над точными UTF-8 body bytes;
- `providerPaymentId` является обязательной непустой строкой и совпадает с `messageId`.

Обозначения receipt `version: 1` и signature `v1=...` относятся только к редакции `week-3.1`, которая отозвала прежний черновик.
